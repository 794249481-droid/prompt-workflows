# Prompt Workflows · 可复用 AI 提示词与工作流

一套面向个人创作者、小团队和业务人员的中文 AI 工作流模板。每份文档都包含适用场景、可复制的提示词、输入参数、输出结构和使用边界，适合直接粘贴到 ChatGPT、Claude、DeepSeek 等工具中，再按自己的情况填写参数。

## 内容导航

| 分类 | 内容 |
| --- | --- |
| 系统设计 | GEO 内容策略、客服导师、知识库、行业情报平台、企业微信机器人 |
| 方案策划 | AI 培训、团队 AI 化、市场研究、直播活动 |
| 内容创作 | 直播脚本、短视频脚本、海报生成 |
| 工作模板 | 入职指南、报名表、政策调研、文件整理 |
| 学习与销售 | 销售教练、产品知识库、互动备考、长篇写作 |

## 使用方法

1. 选择一个与目标接近的 Markdown 文件。
2. 复制“提示词”部分，替换其中的 `[待填写]` 参数。
3. 先用少量真实但已脱敏的数据测试，再逐步补充业务资料。
4. 对需要联网、政策、保险或市场价格的任务，要求模型给出来源、日期和不确定性。

## 公开使用须知

这里是通用模板，不包含聊天记录、客户名单、账号、密钥或公司内部文件。使用时不要把个人信息、商业秘密或未经授权的第三方内容直接粘贴给模型。涉及保险、劳动政策、法律、医疗和财务决策时，应让专业人士复核。

部分模板来自业务场景抽象，示例中的平台、金额和行业可以替换；不要把示例数字当成事实或报价。当前未指定开源许可证。
