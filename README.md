# Prompt Workflows · 三套可复用 AI 工作流

这里保留三套可以直接开始使用的中文 AI 工作流模板：B2B 销售教练、产品知识库搭建、交互式学习备考。每份文档都包含适用场景、可复制的提示词、输入参数、输出结构和使用边界，适合粘贴到 ChatGPT、Claude、DeepSeek 等工具中，再按自己的情况填写参数。

## 内容导航

| 分类 | 内容 |
| --- | --- |
| 销售 | B2B 销售 AI 实战教练 |
| 知识管理 | 产品知识库搭建方案 |

## 使用方法

1. 选择一个与目标接近的 Markdown 文件。
2. 复制“提示词”部分，替换其中的 `[待填写]` 参数。
3. 先用少量真实但已脱敏的数据测试，再逐步补充业务资料。
4. 对需要联网、政策、保险或市场价格的任务，要求模型给出来源、日期和不确定性。

## 公开使用须知

这里是通用模板，不包含聊天记录、客户名单、账号、密钥或公司内部文件。使用时不要把个人信息、商业秘密或未经授权的第三方内容直接粘贴给模型。模板输出需要结合实际资料复核，不能替代专业判断。

部分模板来自业务场景抽象，示例中的平台、金额和行业可以替换；不要把示例数字当成事实或报价。当前未指定开源许可证。
